# 💰 Finance Toolkit

A lightweight Python toolkit for common finance calculations (NPV, IRR, bond pricing, CAPM).

## Features
- NPV (Net Present Value)
- IRR (Internal Rate of Return)
- Bond price given YTM
- CAPM expected return

## Project Structure
- `src/finance.py` → core finance functions
- `main.py` → demo script
- `requirements.txt` → dependencies

## Quickstart
```bash
python -m pip install -r requirements.txt
python main.py 
```
